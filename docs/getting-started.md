# Getting started with Codex CLI

1. [Build and install this fork](install.md).
2. [Provision ChatGPT account-pool authentication](authentication.md).
3. Run `codex` in the project you want it to work on.

For an overview of the interactive CLI features inherited from upstream, see
the [official Codex CLI feature guide](https://developers.openai.com/codex/cli/features#running-in-interactive-mode).
The official installation and authentication instructions describe the
upstream distribution; use this repository's guides for those two areas.
